結論・おすすめ構成

実現可能だが制約あり

セルフパワーUSBハブ経由でスマホへ給電しながらデータ通信する構成は技術的に実現可能です。ただし以下の制約があります:

  • USB 2.0ハブの標準ポートは500mAまで — スマホの充電には不足する場合がある
  • 1A以上の給電にはUSB BC 1.2対応ハブ、充電専用ポート付きハブ、またはUSB 3.0ハブ（900mA）が必要
  • バックフィード（逆流給電）でRaspberry Pi本体が損傷するリスクがある（特にPi 3B以前）

おすすめの実践構成

  1. Pi 4B/5を使用（バックフィード保護が改善されている）
  2. バックフィードしないセルフパワーハブを選定（Plugable USB2-HUB-AG7等）、またはデータ専用USBケーブルで接続
  3. uhubctlでポート電源を制御（sudo apt install uhubctl）
  4. スマホ側でUSBデバッグ（ADB）またはUSBテザリングを有効にしてデータ通信を確保

最重要注意点: バックフィード（逆流給電）

Raspberry Pi本体が損傷する危険性

セルフパワーUSBハブからPiへの「バックフィード」は、Pi本体のポリヒューズ（F1/F2/F3）を迂回して電力が供給されるため、過電流保護が機能しなくなります。

  • ハブのACアダプタが6Vを超える電圧を供給した場合、保護ダイオードD17が過熱し発煙や溶融の危険
  • eLinux.orgに「melts, scorching, smoke or worse」との警告が明記
  • Pi 3B以前のモデルでは特に深刻なリスク
  • Pi 4以降は1.2A電流制限スイッチICが搭載され保護が改善

バックフィード防止策

対策方法難易度効果

uhubctl によるポート電源制御

USBポートの電源をソフトウェアで制御

uhubctl はUSBハブのポートごとの電源制御ユーティリティです。スマホへの給電のON/OFF制御に使えます。

項目内容
インストールsudo apt install uhubctl
対応PiモデルB+, 2B, 3B, 3B+, 4B, 5
Pi 3B以前の制約ポート2-5がganged（連動）制御 — 個別制御不可
Pi 4Bの要件VL805ファームウェア 00137ad 以降へのアップデートが必要
互換ハブ数100以上のモデルが互換性リストに掲載

VBUS制御の落とし穴

一部のUSBハブではポート電源をオフにしてもVBUS（電源供給線）が遮断されないため、接続したスマホが充電され続ける場合があります。コスト削減のためVBUS制御用部品を省略しているハブが多いため、per-port power switching対応の有無を事前に確認してください。

セルフパワー vs バスパワー

方式電源各ポート給電スマホ給電価格帯
セルフパワーACアダプタ（別電源）500mA〜1.5A対応可2,000〜5,000円
バスパワーUSBケーブル経由最大100mA不可500〜2,000円

スマホ給電にはセルフパワー方式が必須です。バスパワーハブは各ポート最大100mAに制限され、スマホへの給電はできません。

未解決の課題・今後の確認事項

  1. 現行品の入手性: 動作実績のある製品（PiHub、Plugable USB2-HUB-AG7等）は2012-2013年頃のUSB 2.0製品で、2026年現在の日本での入手は困難な可能性が高い
  2. USB 3.0ハブの互換性: Pi 4B/5でUSB BC 1.2やPD対応セルフパワーハブを使った場合の安定性について実機検証データが不足
  3. スマホのUSBモード: USBテザリングやADB接続中にハブ経由で給電する場合、「充電モード」と「データ通信モード」の切替が正しく動作するか要確認
  4. Anker等の現行製品: uhubctlの互換性リストに掲載されている現行世代ハブの日本での入手性は要調査
