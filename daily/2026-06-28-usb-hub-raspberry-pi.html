Amazonレビューに基づく安全性評価

RSH-A37S: Raspberry Pi 4Bとの互換性問題あり

AmazonレビューでRaspberry Pi 4Bで起動できないという報告が複数あります。具体的な症状:

  • RPi 4BのUSBブート時にHUB上のHDDを認識できず起動しない
  • Windows 11接続時、何も接続していなくてもスリープ復帰不可になる
  • 原因推定: 5V給電系がPC側に逆流し、電源スイッチのGND検出が誤動作
  • 同メーカー比較テストでRSH-518のみRPi 4Bで正常動作、RSH-A37SとRSH-A35は失敗

ただし「ハブとしての通常使用」（USBブートではなくスマホ接続等）では問題なく動作するレビューも多数。2年以上故障なしとの長期使用報告もあり。RPiからSSDブートする場合は要注意。

USBハブカテゴリのサクラレビュー問題

サクラチェッカーによると、USBハブカテゴリの55%以上がサクラ商品とされています。特に中国メーカーの低価格USBハブはレビュー操作のリスクが高いため、以下に注意:

  • 星5レビューが異常に多い（90%超）製品は疑う
  • UGREENは上場企業で最もブランド信頼度が高い
  • ROSONWAY/RSHTECHはAmazon販売歴が長く一定の実績あり
  • atolla/JESWOは小規模メーカーだが重大事故の報告はなし

RSH-A37Sとの比較（アダプタ交換の可否）

RSH-A37Sは12V DCバレルジャックなので社外12V/5Aアダプタに交換して60W化が可能（非公式）。一方、400-HUBC32GMは5V直接給電のため、アダプタ交換で大幅なワット数アップができません。電力拡張性の面でもRSH-A37Sが優位です。

結論: 良い製品だが今回の用途には合わない

サンワサプライの製品品質・ブランド信頼性は全候補中最高です。スマホ1台+SSD程度の軽い構成なら安心して使えます。しかしスマホ3台+SSDの構成では15Wが致命的に不足し、5Vアダプタのため電力拡張も困難です。予算も¥5,280で超過。今回の要件ではJESWO 11ポート（36W/¥3,689）やRSH-A37S（24W→60W化/¥4,200）の方が適しています。

条件をゆるめるポイント

  • 電力（24Wで妥協）: RSH-A37S付属の24Wでもスマホ3台+SSDは動作する。ただし全デバイスが同時に最大充電すると電力不足で不安定になる可能性あり。実際にはスマホが常に最大900mAを消費するわけではないので、多くの場合は問題ない
  • uhubctl（物理スイッチで妥協）: ソフトウェア制御を諦め、物理スイッチで手動ON/OFFするなら atolla も選択肢に入る
  • 台数（2台に減らす）: スマホ2台+SSDなら必要電力は13.5W。RSH-ST07Cの15Wでも余裕があり、10Gbps+Type-Cの恩恵を受けられる

スマホの充電を維持するには最低500mA、快適に使うなら1A以上が推奨です。USB 2.0ハブでは「充電中」表示にならない場合があります。

USB 3.0ハブの総帯域は5Gbps（共有）です。スマホ3台のADB/テザリングは帯域をほぼ消費しません（計300Mbps程度）。SSDの大容量ファイル転送中にスマホ通信が遅くなることも実用上ほぼありません。帯域は心配不要です。

アダプタ交換という選択肢（自己責任）

Rosonway RSH-A37S は12V DCバレルジャックを使用しており、付属の12V/2A（24W）アダプタを 12V/5A（60W）の社外アダプタに交換すれば電力問題は解消できます。uhubctlチップ（VIA Labs VL822）はアダプタ容量に関係なく動作します。ただしハブ内部の配線や部品の定格電流が不明なため、過電流のリスクがあり非公式な改造となります。

この方法を取る場合: アルミ筐体 + uhubctl対応 + 約3,200円 + 社外アダプタ約1,500円 = 合計約4,700円で60W級のアルミハブが手に入る計算です。

物理スイッチ ≠ uhubctlソフト制御

最重要注意点: バックフィード（逆流給電）

Raspberry Pi本体が損傷する危険性

セルフパワーUSBハブからPiへの「バックフィード」は、Pi本体のポリヒューズ（F1/F2/F3）を迂回して電力が供給されるため、過電流保護が機能しなくなります。

  • ハブのACアダプタが6Vを超える電圧を供給した場合、保護ダイオードD17が過熱し発煙や溶融の危険
  • eLinux.orgに「melts, scorching, smoke or worse」との警告が明記
  • Pi 3B以前のモデルでは特に深刻なリスク
  • Pi 4以降は1.2A電流制限スイッチICが搭載され保護が改善

バックフィード防止策

対策方法難易度効果
バックフィードしないハブを選ぶPlugable USB2-HUB-AG7など実測済み製品を使用簡単最も安全
データ専用USBケーブル電源線（VBUS）が結線されていないケーブルを使用簡単確実
+5V線を物理的に切断USBケーブルのピン1（VBUS/+5V）のみを切断要工作確実
Pi 4B/5を使用電流制限スイッチIC搭載モデルを選択簡単軽減のみ

uhubctl によるポート電源制御

USBポートの電源をソフトウェアで制御

uhubctl はUSBハブのポートごとの電源制御ユーティリティです。スマホへの給電のON/OFF制御に使えます。

項目内容
インストールsudo apt install uhubctl
対応PiモデルB+, 2B, 3B, 3B+, 4B, 5
Pi 3B以前の制約ポート2-5がganged（連動）制御 — 個別制御不可
Pi 4Bの要件VL805ファームウェア 00137ad 以降へのアップデートが必要
互換ハブ数100以上のモデルが互換性リストに掲載

VBUS制御の落とし穴

一部のUSBハブではポート電源をオフにしてもVBUS（電源供給線）が遮断されないため、接続したスマホが充電され続ける場合があります。コスト削減のためVBUS制御用部品を省略しているハブが多いため、per-port power switching対応の有無を事前に確認してください。

セルフパワー vs バスパワー

方式電源各ポート給電スマホ給電価格帯
セルフパワーACアダプタ（別電源）500mA〜1.5A対応可2,000〜5,000円
バスパワーUSBケーブル経由最大100mA不可500〜2,000円

スマホ給電にはセルフパワー方式が必須です。バスパワーハブは各ポート最大100mAに制限され、スマホへの給電はできません。

未解決の課題・今後の確認事項

  1. 現行品の入手性: 動作実績のある製品（PiHub、Plugable USB2-HUB-AG7等）は2012-2013年頃のUSB 2.0製品で、2026年現在の日本での入手は困難な可能性が高い
  2. USB 3.0ハブの互換性: Pi 4B/5でUSB BC 1.2やPD対応セルフパワーハブを使った場合の安定性について実機検証データが不足
  3. スマホのUSBモード: USBテザリングやADB接続中にハブ経由で給電する場合、「充電モード」と「データ通信モード」の切替が正しく動作するか要確認
  4. Anker等の現行製品: uhubctlの互換性リストに掲載されている現行世代ハブの日本での入手性は要調査
